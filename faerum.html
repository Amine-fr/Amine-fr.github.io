Projet jeu faerum

Contexte du projet

Dans le cadre de la ressource Développement Orienté Objets (R2.01), j'ai réalisé un projet en Java consistant à créer un jeu de plateau jouable directement dans le terminal. Le jeu s'appelle Faërun et oppose deux châteaux qui entraînent différents guerriers (elfes, nains et chefs) pour les envoyer combattre sur un plateau. Le but est simple : réussir à atteindre le château adverse avant l'équipe ennemie.

Ce projet avait pour objectif de mettre en pratique les notions de programmation orientée objet vues en cours à travers un projet concret.

Ce que j'ai développé

J'ai développé l'ensemble du jeu en Java en respectant les règles données dans le sujet. J'ai créé les différentes classes représentant les guerriers, les équipes, les châteaux et le plateau.

J'ai également programmé les déplacements des unités, les combats entre les équipes ainsi que les conditions de victoire. Le jeu fonctionne entièrement dans le terminal et permet de simuler une partie complète.

Défis techniques

La principale difficulté a été de gérer toutes les classes du projet et de faire en sorte qu'elles interagissent correctement entre elles. Comme chaque type de guerrier possède des caractéristiques différentes, il fallait bien organiser le code pour éviter les répétitions.

J'ai aussi passé du temps à corriger certains bugs liés aux combats et au déroulement des tours de jeu.

Ce que j'en retiens

Ce projet m'a permis de progresser en Java et surtout de mieux comprendre la programmation orientée objet. C'était l'un de mes premiers projets avec autant de classes et de mécanismes à gérer.

J'ai appris à mieux organiser mon code, à réfléchir à la structure d'un programme avant de le développer et à être plus rigoureux dans les tests. Ce projet m'a aussi montré l'importance d'avancer régulièrement plutôt que de tout faire à la dernière minute.
